GABSI KOTA TANJUNGBALAI — WEBSITE + APLIKASI BRIDGE
======================================================

Isi paket:
- index.html            : website utama / beranda
- score-sheet.html      : Bridge Score Sheet otomatis
- kocokan-kartu.html    : Kocokan kartu pembanding
- manifest.json         : konfigurasi PWA
- sw.js                 : offline cache / service worker
- assets/ketua-gabsi.jpg: foto ketua yang sudah dipoles untuk website
- assets/favicon.svg    : ikon GABSI
- assets/icon-192.png
- assets/icon-512.png

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka index.html pada browser.
3. Untuk penggunaan offline/PWA, gunakan hosting static yang mengaktifkan HTTPS.

CATATAN:
- Website ini tidak memerlukan database/server.
- Data Score Sheet dan Rekap Meja Pembanding disimpan pada localStorage browser.
- Ganti foto kegiatan atau kontak pada index.html sesuai data resmi organisasi.
